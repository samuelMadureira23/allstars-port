# Como contribuir

Este repositório é a apresentação pública do port e o lugar dos relatos de problema. O desenvolvimento pesado acontece fora dele.

## Antes de abrir uma issue

- Leia [docs/PROBLEMAS_COMUNS.md](docs/PROBLEMAS_COMUNS.md). Boa parte dos problemas tem resposta lá.
- Use o template de bug: ele pede a versão do jogo, o build do port, a placa de vídeo, o processador, o Windows, os passos e o log.

## O que enviar em um relato

- A versão do jogo: disco 1.00 ou update 1.12.
- O build do port, se souber.
- O log `user\logs\last_run.log`, revisado antes de anexar, porque ele pode conter caminhos pessoais.
- Captura ou vídeo quando o problema for visual.

## O que não enviar

- EBOOT, `.psarc`, chaves, firmware ou qualquer arquivo extraído do jogo.
- Dumps de memória, executáveis do jogo ou capturas do jogo inteiro.
- Dados pessoais que não sejam necessários para reproduzir o problema.

## Sugestões de mudança

Este repositório não aceita pull request de código no momento. Se você tem uma correção ou uma ideia, abra uma issue descrevendo o problema e, se possível, o trecho de código e o teste que comprova a correção. A mudança é avaliada e, se fizer sentido, aplicada no repositório de desenvolvimento.
