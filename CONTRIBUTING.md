# Contributing

For bugs, open an issue or contact `samukambr` on Discord. Include the game version, build or commit, hardware, expected result and steps to reproduce. Remove personal paths, addresses and account details from logs before sharing them.

For code changes, explain the problem, describe the fix and record the relevant validation. Keep unrelated changes separate. The [engineering overview](docs/ENGINEERING.md) describes what is included in this development snapshot.

Do not commit game executables, generated game code, assets, firmware, decryption keys, saves, personal configuration or credentials. Use environment variables for local paths. Preserve third-party license notices and author attribution in patches.

Report security issues privately to `samukambr` on Discord; see the [security policy](.github/SECURITY.md).
